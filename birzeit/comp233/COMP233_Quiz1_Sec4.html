Notation: ¬ is “not”; lower-case c is a contradiction (not the course set C in Q3). In marking, ~ or ∼ for ¬, and ∴ or “therefore” for a conclusion, were all accepted. Any logically equivalent answer earned full marks unless a part says otherwise.

Q1
Translation, contrapositive and negation
20 pts

Let p = “The battery is charged”, q = “The device turns on”, and r = “The device is faulty.”

Q1.a
10 pts (5 each)
Formalise each statement in symbols:
  1. A charged battery is sufficient for the device to turn on.
  2. Neither is the battery charged nor does the device turn on.
Worked solution
(i) p → q  (equivalently ¬q → ¬p)

“p is sufficient for q” means p → q: whenever the battery is charged, the device turns on.

(ii) ¬p ∧ ¬q  (equivalently ¬(p ∨ q))

“Neither A nor B” means “not A and not B”.

Marking guide (10 pts).
  • (i) 5 pts. 0 pts for q → p (direction reversed, which would be “necessary”). Full marks for any equivalent form.
  • (ii) 5 pts. 2 pts for ¬p ∨ ¬q or ¬(p ∧ q); 0 pts for other connectives.
Q1.b
10 pts (5 each)
For the proposition “If the battery is charged and the device does not turn on, then the device is faulty”, write its contrapositive and its negation in symbols. In your final answers, ¬ should apply only to single variables.
Worked solution
Statement (p ∧ ¬q) → r
Contrapositive ¬r → ¬(p ∧ ¬q)  ≡  ¬r → (¬p ∨ q)

Swap and negate both sides, then apply De Morgan’s law and double negation so that ¬ sits on single variables.

Negation ¬((p ∧ ¬q) → r)  ≡  (p ∧ ¬q) ∧ ¬r  ≡  p ∧ ¬q ∧ ¬r

The negation of A → B is A ∧ ¬B: the hypothesis holds and the conclusion fails. It is not a conditional.

Marking guide (10 pts).
  • Contrapositive, 5 pts: 3 for the correct structure ¬r → ¬(p ∧ ¬q), 2 for applying De Morgan’s law and double negation to reach ¬p ∨ q. 0 pts for the converse or inverse.
  • Negation, 5 pts: 2 for ¬((p ∧ ¬q) → r) without expansion; full marks for p ∧ ¬q ∧ ¬r. 0 pts if the negation is written as a conditional.

Q2.b
10 pts
Simplify (p → q) ∧ (p → ¬q) using logical equivalences. Name the law used at each step. Do not use a truth table.
Worked solution
(p → q) ∧ (p → ¬q)given
≡ (¬p ∨ q) ∧ (¬p ∨ ¬q)implication law (p → q ≡ ¬p ∨ q), applied twice
≡ ¬p ∨ (q ∧ ¬q)distributive law
≡ ¬p ∨ cnegation law (q ∧ ¬q ≡ c)
≡ ¬pidentity law (¬p ∨ c ≡ ¬p)

Final answer: (p → q) ∧ (p → ¬q) ≡ ¬p.

Marking guide (10 pts).
  • 3 pts: the implication law step.
  • 3 pts: the distributive step.
  • 2 pts: the negation law.
  • 2 pts: the identity law.
Deduct 1 pt per step whose law is not named (max −3). Other correct orders of equivalent steps were accepted. 0 pts if a truth table is used instead.

Q3
Quantified statements and multiple quantifiers
45 pts
Q3.a
15 pts (5 each)
The domain is all employees of a company. Let M(x) = “x is a manager,” T(x) = “x has completed the security training,” and K(x) = “x holds a key card.” Consider:
“Every manager who has completed the security training holds a key card.”
Write in symbols: (i) the statement, (ii) its contrapositive, (iii) its negation, and also give the negation as an English sentence. ¬ should apply only to predicates.
Worked solution
(i) Statement ∀x, (M(x) ∧ T(x)) → K(x)
(ii) Contrapositive ∀x, ¬K(x) → ¬(M(x) ∧ T(x))  ≡  ∀x, ¬K(x) → (¬M(x) ∨ ¬T(x))
(iii) Negation ∃x, M(x) ∧ T(x) ∧ ¬K(x)

In English: “There is a manager who has completed the security training but does not hold a key card.” (Equivalently: some manager who completed the training has no key card.)

The negation of ∀x, A(x) → B(x) is ∃x, A(x) ∧ ¬B(x): the quantifier flips and the conditional becomes a conjunction.

Marking guide (15 pts).
  • (i) 5 pts. 2 pts if ∧ is used instead of → (∀x, M(x) ∧ T(x) ∧ K(x)); 3 pts if the hypothesis omits one of M(x), T(x).
  • (ii) 5 pts: 3 for the correct structure, 2 for De Morgan giving ¬M(x) ∨ ¬T(x). 0 pts for the converse or inverse.
  • (iii) 5 pts: 3 for the symbolic negation (must be ∃ with a conjunction; 1 pt if written ¬∀x, … without moving the negation inside), 2 for a correct English sentence. 0 pts for the symbolic part if it contains →.

For parts (b)–(d), let S be a set of students and C a set of courses, and let T(x, y) mean “student x has taken course y.”

Note: T(x, y) is a new two-place predicate, unrelated to T(x) in part (a).

Q3.b
10 pts (5 each)
Formalise, using quantifiers with the specified domains:
  1. Every course has been taken by at least one student.
  2. Some student has taken every course.
Worked solution
(i) ∀y ∈ C, ∃x ∈ S, T(x, y)
(ii) ∃x ∈ S, ∀y ∈ C, T(x, y)

Read each formula from the left: in (i) the course is chosen first and the student may depend on it; in (ii) one student is fixed first and must work for every course.

Marking guide (10 pts, 5 each). Quantifier order swapped: 2 pts. Domains missing or wrong (e.g., x ranging over C): deduct 1 pt. Both answers identical: at most 5 pts for the pair.

Q3.d
10 pts
Let S = {Ali, Dana, Noor} and C = {Logic, Algebra}. The only courses taken are: Ali took Logic, Dana took Algebra, and Noor took Logic. Determine the truth value of statements (i) and (ii) from part (b), and justify each. What does this example show about whether (i) implies (ii)?
Worked solution

(i) True. Each course has at least one student: Logic was taken by Ali (and Noor); Algebra was taken by Dana. In the table, every column contains a T.

(ii) False. No student has taken both courses: Ali and Noor have not taken Algebra, and Dana has not taken Logic. In the table, no row is all T. Equivalently, the negation from part (c) holds: for every student there is a course not taken.

Conclusion. This example makes (i) true and (ii) false, so (i) does not imply (ii). The order of ∀ and ∃ matters: ∃x ∀y is stronger than ∀y ∃x.

Marking guide (10 pts).
  • (i) 4 pts: 1 for True, 3 for naming a student for each course.
  • (ii) 4 pts: 1 for False, 3 for showing every student misses some course (or that no student has both).
  • 2 pts: stating that (i) does not imply (ii).
If your own formalisations in (b) were wrong but your evaluation is consistent with them, at most 2 pts per part.
