Relations

What a relation is, its matrix and directed graph, the three core properties (reflexive, symmetric, transitive), and equivalence relations with their classes and partitions. Sections 8.1–8.3.
Back to COMP233

About this chapter

A relation records which elements are connected to which. “Is less than”, “divides”, “has the same remainder as”, “is a friend of” — each is just a set of ordered pairs. This is the same raw material as Chapter 7: a function is a special relation (every input related to exactly one output), so here we drop that restriction and study connections in full generality.

The thread. Section 8.1 defines a relation and gives three ways to see it: as a set of pairs, as a matrix, and as a directed graph. Section 8.2 asks three yes/no questions about a relation on a set — is every element related to itself (reflexive), does every arrow have a return arrow (symmetric), and do two-step links close up (transitive). Section 8.3 combines all three into an equivalence relation, the precise idea of “being the same in some respect”, which cuts a set cleanly into classes.

Section 8.1Relations on sets

Definition · relation
A relation R from a set A to a set B is a subset of the Cartesian product A × B. We write x R y (“x is related to y”) to mean (x, y) ∈ R, and x ⅀ y to mean (x, y) ∉ R. When B = A we call it a relation on A.

That single line is the whole idea: a relation is just a chosen set of ordered pairs. Chapter 6 built A × B (every possible pair); a relation simply picks out the pairs you care about. Because it is a set, everything you know about sets — subset, union, complement — applies to relations too.

  • The domain of R is the set of x that appear as a first coordinate of some pair.
  • The range (or image) is the set of y that appear as a second coordinate.
  • A relation can be drawn three equivalent ways: as a set of pairs, as a 0/1 matrix, or as a directed graph (when it is a relation on one set).

A relation generalises a function. A function f : A → B is exactly a relation in which every x ∈ A appears as a first coordinate exactly once. Relations relax that: an x may relate to several elements, or to none.

8.1.1 Relation explorer — pairs, matrix, domain and range

Enter a domain A, a co-domain B, and the relation as x:y pairs. The tool shows the relation as a set, builds the 0/1 matrix (row x, column y is 1 exactly when x R y), and reports the domain and range. Leave B empty to make it a relation on A.

8.1.2 Directed graph of a relation on a set

For a relation on a single set, the clearest picture is a directed graph: one node per element, and an arrow x → y for every pair (x, y). A pair (x, x) is a self-loop. Watch how the three properties of Section 8.2 look here: a self-loop at every node (reflexive), every arrow paired with its reverse (symmetric), and every two-step path having a direct shortcut (transitive).
arrow x→y self-loop = (x,x)

8.1.3 Standard relations — see the famous ones

The relations you will meet again and again are defined by a rule, not a list. Pick one on the set {1, 2, …, n} and the tool generates its pairs, matrix and graph so you can feel its shape. These are Examples 8.1.3–8.1.4 (“divides”, “≤”, congruence) brought to life.
Definition · the inverse relation
The inverse of R (from A to B) is R⁻¹ = { (y, x) : (x, y) ∈ R }, a relation from B to A — just reverse every arrow. In the matrix this is the transpose (swap rows and columns). For example, the inverse of “<” is “>”, and the inverse of “is a child of” is “is a parent of”. The 8.1.1 explorer prints R⁻¹ for whatever you type.

Practice exercises · Section 8.1

Epp, 4th ed. §8.1: recommended 1, 2, 9, 10, 13, 15, 16. Try each on paper first, then reveal.
Exercise 8.1 A
Let A = {2, 3, 4} and B = {6, 8, 10}, and define x R y ⇔ x | y (x divides y). List R as a set of pairs and give its domain and range.
Test every pair: 2|6, 2|8, 2|10 all hold; 3|6 holds, 3|8 no, 3|10 no; 4|8 holds, 4|6 no, 4|10 no. R = {(2,6),(2,8),(2,10),(3,6),(4,8)}. Domain = {2,3,4} (all of them appear as a first coordinate); range = {6,8,10} (all appear as a second coordinate).
Exercise 8.1 B
On A = {0, 1, 2, 3} let x R y ⇔ 2 | (x + y) (the sum is even). Find R and its inverse R⁻¹. What do you notice?
x + y is even exactly when x and y have the same parity. Even members: {0,2}; odd: {1,3}. R = all pairs within {0,2} plus all within {1,3} = {(0,0),(0,2),(2,0),(2,2),(1,1),(1,3),(3,1),(3,3)}. R⁻¹ = R: reversing each pair gives a pair already present. A relation equal to its own inverse is precisely a symmetric one (Section 8.2) — and this one is in fact an equivalence relation (“same parity”).

Section 8.2Reflexivity, symmetry, and transitivity

For a relation on a single set A, three properties come up constantly. Each is a statement about all elements, so to prove one you argue about an arbitrary case, and to disprove it you give a single counterexample.

The three properties
Reflexive (انعكاسية): ∀ x ∈ A,   x R x. Every element relates to itself — a self-loop at every node.
Symmetric (تماثلية): ∀ x, y ∈ A,   x R y ⇒ y R x. Every arrow has a return arrow.
Transitive (تعدية): ∀ x, y, z ∈ A,   (x R y ∧ y R z) ⇒ x R z. Every two-step path has a one-step shortcut.

The negations tell you exactly what a counterexample looks like:

NOT reflexive
some x with x ⅀ x (one missing self-loop).
NOT symmetric
some x, y with x R y but y ⅀ x (a one-way arrow).
NOT transitive
some x, y, z with x R y, y R z, but x ⅀ z (a broken shortcut).
Watch the difference: “reflexive” vs “a self-loop somewhere”
Reflexive demands a self-loop on every element. A relation with one or two self-loops but not all of them is not reflexive. Also note the empty relation on a non-empty set is not reflexive (it has no self-loops), yet it is vacuously symmetric and transitive — there is no arrow to violate those.

8.2.1 Property checker — with the exact witness

Enter a relation on a set and the checker tests all three properties. When one fails it names the witness: the element missing a self-loop, the one-way arrow, or the two-step chain whose shortcut is missing. The directed graph marks missing self-loops with a dashed red ring and draws every arrow, so you can see the verdict, not just read it.
Try presets: symmetric, not transitive · a partial order (≤) · transitive, not reflexive/symmetric (<) · an equivalence relation
Worked proof · congruence mod 3 is transitive
Claim: on Z, define a R b ⇔ 3 | (a − b). Then R is transitive.
Suppose a R b and b R c for arbitrary integers. By definition 3 | (a − b) and 3 | (b − c), so a − b = 3s and b − c = 3t for some integers s, t.
Add: (a − b) + (b − c) = a − c = 3s + 3t = 3(s + t). Since s + t ∈ Z, we get 3 | (a − c), i.e. a R c. ∎

This is the model for “prove transitive”: assume the two hypotheses x R y and y R z using the definition, then manipulate to reach x R z. Reflexive and symmetric proofs follow the same shape with one fewer hypothesis.

8.2.2 Transitive closure — the smallest fix

If a relation is not transitive, its transitive closure Rᵗ is the smallest superset of R that is transitive: keep adding the missing shortcut (x, z) whenever x R y and y R z, until nothing new appears. Equivalently, x Rᵗ z iff there is a directed path x → … → z of length ≥ 1. The tool lists the pairs it adds, round by round.

Practice exercises · Section 8.2

Epp, 4th ed. §8.2: recommended 2, 3, 10, 12, 13, 14, 15, 18. More are solved in Taught solutions.
Exercise 8.2 A
On A = {1, 2, 3} let R = {(1,1),(2,2),(3,3),(1,2),(2,1),(2,3),(3,2)}. Which of reflexive, symmetric, transitive hold? Give a witness for any that fail.
Reflexive: yes — (1,1),(2,2),(3,3) are all present. Symmetric: yes — (1,2)/(2,1) and (2,3)/(3,2) both come in pairs. Transitive: no. We have (1,2) and (2,3) but (1,3) is missing — the shortcut is broken. Witness: x=1, y=2, z=3.
Exercise 8.2 B
Define R on Z by a R b ⇔ a · b > 0 (same sign, both non-zero). Is it reflexive? symmetric? transitive?
Reflexive: no — 0 · 0 = 0, not > 0, so 0 ⅀ 0. (It is reflexive on the non-zero integers, but not on all of Z.) Symmetric: yes — ab > 0 ⇒ ba > 0. Transitive: yes — if ab > 0 and bc > 0 then a and b share a sign, and b and c share a sign, so a and c share a sign, giving ac > 0. Domain matters: the verdict on “reflexive” flips between Z and Z − {0}.

Section 8.3Equivalence relations

Definition · equivalence relation
A relation on A is an equivalence relation if it is reflexive, symmetric, and transitive — all three at once. It captures the idea of being “the same in some respect”: equal, same remainder, same parity, same length, same colour.
Definition · equivalence class
For a ∈ A, the equivalence class of a is [a] = { x ∈ A : x R a } — everything related to a. Any member of a class can serve as its name (a representative).
Theorem 8.3.1 & 8.3.4 · classes partition the set
If R is an equivalence relation on A, then its distinct equivalence classes form a partition of A: every element lies in exactly one class. The key facts: a R b ⇔ [a] = [b], and any two classes are either identical or disjoint — never partly overlapping. Conversely (Theorem 8.3.4), any partition of A defines an equivalence relation (“in the same block”). So equivalence relations and partitions are two views of the same thing.

This is why equivalence relations matter so much in computing: they are exactly the tool for grouping — deduplicating records by a key, bucketing by hash, identifying states in an automaton, or reducing fractions (every fraction names one rational number, and “equals the same rational” is an equivalence relation).

8.3.1 Equivalence checker — and the classes it produces

Enter a relation on a set. The tool checks the three properties; if all hold, it is an equivalence relation and the tool computes the equivalence classes and shows the partition. If any property fails, it names the witness so you can see why it is not an equivalence relation.

8.3.2 Congruence mod n — the model example

The most important equivalence relation: a ≡ b (mod n) means n | (a − b), i.e. a and b leave the same remainder on division by n. It splits the integers into exactly n classes [0], [1], …, [n−1] (the residue classes). Pick n and a range to see the classes, and test any two integers.

8.3.3 Partition ↔ relation — the two-way street

Enter a partition as blocks separated by |, each block a space- or comma-list, e.g. 1 2 | 3 | 4 5. The tool builds the induced equivalence relation (“x ~ y iff same block”) — all pairs within each block — and confirms the three properties hold automatically. This is Theorem 8.3.4 made concrete.

Practice exercises · Section 8.3

Epp, 4th ed. §8.3: recommended 1, 9, 10, 15, 16, 24, 28, 30. More in Taught solutions.
Exercise 8.3 A
On A = {0, 1, 2, 3, 4, 5} define a R b ⇔ 3 | (a − b). Show it is an equivalence relation and list the classes.
Reflexive: 3 | (a − a) = 0. Symmetric: if 3 | (a − b) then 3 | (b − a) (negate). Transitive: shown in 8.2 (add the multiples of 3). So it is an equivalence relation. Classes = group by remainder mod 3: [0] = {0, 3}, [1] = {1, 4}, [2] = {2, 5}. These three blocks partition A.
Exercise 8.3 B
How many different equivalence classes does “a ≡ b (mod 5)” have on all of Z, and which integers lie in [2]?
Five classes, one per possible remainder: [0], [1], [2], [3], [4]. (More representatives exist — [5] = [0] — but only five distinct classes.) [2] = { …, −8, −3, 2, 7, 12, 17, … } = { 5k + 2 : k ∈ Z } — every integer leaving remainder 2.

WorkedTaught solutions to recommended exercises

A selection from Epp’s recommended problems (4th ed.), solved in the style used in lecture. Attempt each on paper first.
§8.1 · a relation from its rule
Let A = {1, 2, 3, 4} and define x R y ⇔ x + y is even. Write R, then read off whether it is reflexive, symmetric, transitive.
Same-parity pairs. Evens {2,4}, odds {1,3}. R = {(1,1),(1,3),(3,1),(3,3),(2,2),(2,4),(4,2),(4,4)}. Reflexive (each (a,a) present, since a+a=2a is even), symmetric (x+y=y+x), transitive (same parity is “the same in a respect”). It is an equivalence relation with classes {1,3} and {2,4}.
§8.2 · prove symmetric
On Z, a R b ⇔ 5 | (a − b). Prove R is symmetric.
Suppose a R b, so 5 | (a − b), i.e. a − b = 5k for some k ∈ Z. Then b − a = −5k = 5(−k), and −k ∈ Z, so 5 | (b − a), i.e. b R a. Hence R is symmetric. ∎
§8.2 · disprove transitive
On A = {a, b, c} let R = {(a,b),(b,c)}. Is R transitive? Make it transitive by adding the fewest pairs.
Not transitive: (a,b) and (b,c) are present but (a,c) is not — the shortcut is missing. Add (a,c). Now check again: the only two-step paths are a→b→c (shortcut (a,c) now present). So Rᵗ = {(a,b),(b,c),(a,c)} is the transitive closure — one pair suffices.
§8.3 · verify an equivalence relation
On the set of all strings over {0,1}, define s R t ⇔ s and t have the same length. Show it is an equivalence relation and describe the classes.
Reflexive: s has the same length as itself. Symmetric: if len(s)=len(t) then len(t)=len(s). Transitive: equal lengths chain through. So it is an equivalence relation (it is “same value of the function length” — every function induces such a relation). Classes: one class per length: [ε] = {ε} (length 0), length-1 strings {0, 1}, length-2 strings {00,01,10,11}, and so on.
§8.3 · classes of congruence
For congruence mod 4 on Z, list the four classes and decide whether −6 and 10 are in the same class.
[0]={…,−4,0,4,8,…}, [1]={…,−3,1,5,…}, [2]={…,−2,2,6,10,…}, [3]={…,−1,3,7,…}. −6 mod 4: −6 = 4·(−2) + 2, remainder 2. 10 = 4·2 + 2, remainder 2. Same remainder ⇒ same class [2]. Equivalently 4 | (10 − (−6)) = 16. ✓
§8.3 · partition to relation
The partition of {1,2,3,4,5} into {1,4,5} and {2,3} induces which relation? How many pairs does it contain?
“Same block” gives all ordered pairs within each block. Block {1,4,5} contributes 3² = 9 pairs; block {2,3} contributes 2² = 4 pairs. Total 9 + 4 = 13 pairs. In general a block of size k contributes k² pairs, and the induced relation is automatically reflexive, symmetric and transitive.

HarderChallenge problems — and how to crack them

Tougher problems that reward real understanding. Each solution shows the idea first, then the steps.
Challenge 1 the classic trap
A student “proves”: symmetric + transitive ⇒ reflexive — “if x R y then by symmetry y R x, and then by transitivity x R x.” Find the flaw and give a relation that is symmetric and transitive but not reflexive.
The flaw: the argument needs an x that is related to some y to start. If an element x is related to nothing, the chain never begins, so x R x is never forced. Counterexample: on A = {1, 2} take R = {(1,1)}. It is symmetric (the only pair is its own reverse) and transitive (the only chain 1→1→1 closes), but not reflexive because (2,2) is missing — element 2 is related to nothing. (The empty relation on any non-empty set is the extreme case.) Lesson: reflexivity is genuinely independent — it must be checked on its own, and the property checker (8.2.1) will flag exactly the orphaned element.
Challenge 2 count the structures
How many different equivalence relations are there on a 4-element set? (Equivalently, how many ways to partition it.)
Idea: by Theorem 8.3.4 an equivalence relation is a partition, so just count partitions of {1,2,3,4}. Count by block-size shape. 1 block of 4: 1 way.   3+1: C(4,3)=4.   2+2: C(4,2)/2 = 3 (divide by 2 because the two pairs are interchangeable).   2+1+1: C(4,2)=6.   1+1+1+1: 1. Total 1 + 4 + 3 + 6 + 1 = 15. (These are the Bell numbers: B₀..B₄ = 1, 1, 2, 5, 15.) The counting tools of Chapter 9 are exactly what makes this systematic.
Challenge 3 prove it carefully
On R (the reals) define x R y ⇔ x − y ∈ Z (their difference is an integer). Prove it is an equivalence relation and describe [0] and [0.5].
Reflexive: x − x = 0 ∈ Z. Symmetric: if x − y ∈ Z then y − x = −(x − y) ∈ Z. Transitive: if x − y ∈ Z and y − z ∈ Z, add them: x − z ∈ Z (sum of integers). So it is an equivalence relation. Classes group reals by their fractional part. [0] = Z (all integers); [0.5] = { …, −1.5, −0.5, 0.5, 1.5, … } = { n + 0.5 : n ∈ Z }. There is one class for each value in [0, 1) — this is the circle you get by “gluing” the number line at every integer.
Challenge 4 build to order
On A = {1,2,3,4}, construct a relation that is reflexive and symmetric but not transitive, using as few pairs as possible. Then take its transitive closure.
Idea: link 1–2 and 2–3 symmetrically but leave 1–3 out; add all self-loops for reflexivity. R = {(1,1),(2,2),(3,3),(4,4),(1,2),(2,1),(2,3),(3,2)}. Reflexive ✓, symmetric ✓. Not transitive: (1,2),(2,3) present but (1,3) missing. Transitive closure forces (1,3) and, by symmetry of the result, (3,1). Now {1,2,3} is fully connected, so the closure becomes the equivalence relation with classes {1,2,3} and {4} — a nice illustration that closing a reflexive-symmetric relation transitively yields an equivalence relation.

Chapter recap — relations, end to end

  • 8.1 — a relation is a subset of A × B (a chosen set of pairs); see it as pairs, a 0/1 matrix, or a directed graph; know domain, range, and the inverse R⁻¹ (reverse the arrows / transpose the matrix). A function is the special case “each input exactly once”.
  • 8.2 — on one set, test reflexive (self-loop on every element), symmetric (every arrow has its reverse), transitive (every two-step path has a shortcut). Prove with an arbitrary case from the definition; disprove with one counterexample. The transitive closure is the smallest transitive enlargement.
  • 8.3 — reflexive + symmetric + transitive = an equivalence relation; its classes [a] partition the set (equal or disjoint, never overlapping). Partitions and equivalence relations are the same data. Congruence mod n is the model: n classes by remainder.
The link forward. Counting the equivalence relations in Challenge 2 needed the multiplication rule and combinations — exactly the toolkit of Chapter 9 (Counting & Probability), where “how many ways?” becomes a method rather than a guess.
