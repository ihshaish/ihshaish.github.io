Unpacking a use case into an activity diagram

A use case diagram says what the system does; an activity diagram shows how one use case flows, in what order, with which decisions, and who does each step. Here we take the Book room use case and unpack its description (left) into a flow.

Book room · use case description

Actors  Guest, Payment Provider
Pre  at least one room is available
1  Guest selects a room
2  Guest enters details and card
3  System requests authorisation from the provider
4  On approval, the room is reserved
5  Booking is confirmed
Alt  if declined, re-enter and retry; if no room, end
