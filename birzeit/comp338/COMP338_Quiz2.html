Q1
Adversarial search: concepts
[ 40 marks ]
Answer each part briefly in the space provided.
Q1.a · Minimax
8 pts
In one or two sentences, state what value the minimax algorithm computes for the root of a game tree, and the assumption it makes about the opponent.
Your answer
Model answer

Minimax returns the minimax value of the root: the utility MAX can guarantee assuming optimal play by both sides, i.e. the value of the terminal reached when MAX always maximises and MIN always minimises. It assumes the opponent (MIN) plays optimally, always choosing the move that minimises MAX's payoff (a worst-case assumption).

Marking: 4 pts for ‘the best value MAX can guarantee / value under optimal play’; 4 pts for ‘assumes an optimal (worst-case) opponent that minimises MAX’.
Q1.b · Terminology
8 pts
Define each term: (i) ply, (ii) terminal state, (iii) utility (payoff) function, (iv) zero-sum game.
Your answer
Model answer

(i) Ply: one move by one player, i.e. one level of the game tree. (ii) Terminal state: a state where the game has ended (win / lose / draw) and has no successors. (iii) Utility / payoff function: a number giving the value of a terminal state to MAX. (iv) Zero-sum game: one player's gain is exactly the other's loss, so the two players' utilities sum to a constant (the interests are strictly opposed).

Marking: 2 pts each. Accept ‘half-move’ for ply; ‘constant-sum’ for zero-sum.
Q1.c · Complexity
8 pts
Give the time and space complexity of minimax for a tree of depth m and branching factor b. Then, for chess (b ≈ 35, m ≈ 100), explain in one sentence why exact minimax is infeasible.
Your answer
Model answer

Time O(bm) (it visits every node); space O(bm) for the depth-first version. For chess, bm ≈ 35100 is astronomically large, far more nodes than could be examined in any feasible time, so a complete minimax search to the terminals cannot be run.

Marking: 3 pts time, 2 pts space, 3 pts for the infeasibility explanation (the exponential bm is too large). Do not penalise O(m) vs O(bm) for space.
Q1.d · Alpha–beta basics
10 pts
(i) What does alpha–beta pruning guarantee about the value it returns, compared with plain minimax? (ii) Define α and β, and give the value each starts with at the root.
Your answer
Model answer

(i) It returns exactly the same value (and move) as minimax; pruning never changes the result, it only avoids examining nodes that cannot affect it. (ii) α is the highest value MAX is already guaranteed along the current path (MAX's best alternative so far), starting at −∞ and only rising; β is the lowest value MIN is already guaranteed along the path (MIN's best alternative so far), starting at +∞ and only falling.

Marking: 4 pts for ‘same result as minimax’; 3 pts for α (meaning + start −∞); 3 pts for β (meaning + start +∞).
Q1.e · Move ordering
6 pts
With ideal move ordering, alpha–beta examines about O(bm/2) nodes. (i) What practical benefit does this give for the same amount of computation? (ii) Does the order in which children are examined change the value returned at the root? Justify.
Your answer
Model answer

(i) Halving the exponent lets alpha–beta search roughly twice as deep in the same time. (ii) No. Move ordering changes only how many nodes are pruned (how much work the search costs); the value (and best move) returned is always the exact minimax value, whatever the order.

Marking: 3 pts for ‘about twice the depth / search deeper’; 3 pts for ‘no, the result is unchanged, only the work changes’.

Q2.d · The cut at C
6 pts
The search skips part of node C. State whether this is an α-cut or a β-cut, and explain in one sentence why the rest of C can be skipped.
Your answer
Model answer

It is an α-cut (a cut at a MIN node). MAX is already guaranteed 8 via B; C is a MIN node whose value is already ≤ 7 (from its first child G), so MAX would never choose C and the rest of C cannot change the result.

Marking: 2 pts for ‘α-cut’; 4 pts for the reason (MAX already has ≥ 8, C can only be ≤ 7, so it is irrelevant).
Q2.e · A beta-cut, and the rule
6 pts
Name one cut in this tree that is a β-cut (give the node), and state the general rule for when a β-cut occurs.
Your answer
Model answer

A β-cut occurs at node F (and again at J). General rule: at a MAX node, as soon as its value rises to ≥ β, stop examining its remaining children – the MIN ancestor already has a reply at least that good and would never let play reach this node.

Marking: 2 pts for a correct β-cut node (F or J); 4 pts for the rule (at a MAX node, prune when value ≥ β).
